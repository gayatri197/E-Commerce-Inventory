# E-Commerce Inventory CLI Project

## Description
A simple command-line Java application to manage an e-commerce inventory system using MySQL database.

## Features
- Manage product categories
- Add, update, and list products
- Connects to MySQL database using JDBC
- SQL scripts to set up database schema and sample data

## Prerequisites
- Java JDK (version X or higher)
- MySQL Server installed and running
- Git (optional, for cloning repo)
- IntelliJ IDEA or any Java IDE (optional)
